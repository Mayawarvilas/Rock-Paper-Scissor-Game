A simple and interactive Rock–Paper–Scissors game built using pure HTML, CSS, and JavaScript.
This project allows users to play against the computer with instant visual feedback and score tracking
<br>
The user selects Rock, Paper, or Scissors.
JavaScript generates the computer’s choice randomly.
The game compares both choices using simple rules:
  Rock beats Scissors
  Scissors beats Paper
  Paper beats Rock
The result is displayed instantly along with updated scores.
The user can play unlimited rounds
